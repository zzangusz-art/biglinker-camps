# 캠프 상담 DB 연결 — 설정 가이드 (10분)

홈페이지의 상담 신청, 기관·파트너 문의, 캠프 진단 결과 상담을 **구글 시트에 한 줄씩 저장**하고 **메일로 알림**(선택: 슬랙)을 받습니다.
비용 없음. 회사 공용 구글 계정(예: biglinkerkor@gmail.com)으로 진행하세요.

## 1. 시트 만들기
1. 구글 드라이브 → 새로 만들기 → 구글 스프레드시트 → 이름 `BigLinker Camps 상담 DB`
2. 상단 메뉴 **확장 프로그램 → Apps Script**
3. 기본 코드를 모두 지우고 같은 폴더의 `Code.gs` 내용을 붙여넣기
4. 맨 위 `NOTIFY_TO` 에 알림 받을 메일 주소 확인 (여러 명이면 쉼표)
5. 저장

## 2. 권한 승인
1. 함수 선택에서 `setup` 선택 → **실행**
2. "승인 필요" → 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용
   (본인이 만든 스크립트라 뜨는 표준 경고입니다. 시트·메일 권한을 요청합니다.)
3. 시트에 `캠프 상담 DB` 탭이 생기면 성공
4. `testPost` 실행 → 시트에 테스트 1줄 + 알림 메일 1통이 오는지 확인 → 테스트 행은 삭제

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → 유형 **웹 앱**
3. 실행 계정: **나** / 액세스 권한: **모든 사용자**
4. 배포 → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`) 복사

## 4. 홈페이지에 연결
`assets/config.js` 의 `LEAD_ENDPOINT: ''` 따옴표 안에 3번 URL을 붙여넣고 저장 → 커밋·푸시(1~2분 뒤 반영).
URL을 알려 주시면 연결과 배포는 대신 해 드릴 수 있습니다.

## 5. 실제 점검 (꼭 하세요)
1. 휴대폰으로 홈페이지 접속 → 상담 신청 → 제출
2. 화면에 **접수번호(BC로 시작)**가 뜨는지
3. 시트에 행이 생기고 구분·역할·연락처·관심 캠프가 제자리에 들어갔는지
4. 알림 메일이 왔는지 (신청자가 이메일을 적었다면 메일에서 바로 '답장'하면 신청자에게 갑니다)

화면에 "접수되었습니다"가 떠도 **시트에 행이 생긴 것까지 확인**해야 진짜 연결된 것입니다.

## 시트 열 구성
접수일시 · 접수번호 · 상태 · 구분 · 역할 · 이름 · 연락처 · 이메일 · 학년·나이 · 관심 캠프 · 희망 시기 · 문의 내용 · 진단 조건 · 사이트 언어 · utm_source · utm_medium · utm_campaign · 검색어 · gclid · 유입 referrer · 첫 랜딩 · 신청 페이지 · 기기 · 작성시간(초)

- **구분**: `상담`(일반 상담) / `기관·파트너`(학교·기관·에이전시를 고르거나 파트너 문의 버튼으로 들어온 경우) / `진단 결과 상담`(캠프 진단 결과 화면에서 신청)
- **상태(C열)**: `접수 → 상담 중 → 자료 발송 → 상담 완료 → 등록 / 보류 / 취소`
- **진단 조건**: 캠프 진단에서 고른 학년·방향·니즈·지역 등이 그대로 들어갑니다.
- 광고 유입 분석: O열부터 utm·검색어·gclid·첫 랜딩 페이지가 저장됩니다.
- 같은 연락처로 2분 안에 다시 제출하면 새 줄을 만들지 않고 처음 접수번호를 돌려줍니다.
- 메일 한도: 일반 구글 계정 하루 100통 (초과해도 시트 저장은 정상).

## 전송이 실패하면
네트워크 문제로 접수가 확인되지 않으면 화면에 "접수를 완료하지 못했습니다"가 뜨고, 작성 내용을 복사·메일로 보낼 수 있게 보여 줍니다.
내용은 그 기기에 보관했다가 다음 방문 때 자동으로 다시 보냅니다.

## 슬랙 알림 (선택)
1. 슬랙에서 **Incoming Webhook URL** 발급
2. Apps Script 왼쪽 **프로젝트 설정 → 스크립트 속성 → 속성 추가**: 이름 `SLACK_WEBHOOK`, 값 = 웹훅 URL
3. URL은 서버(스크립트 속성)에만 있으므로 홈페이지 코드에 노출되지 않습니다.

## 코드를 고친 뒤
**배포 → 배포 관리 → 편집 → 버전: 새 버전 → 배포** (URL이 바뀌지 않음). '새 배포'를 다시 만들면 URL이 바뀌니 주의.
